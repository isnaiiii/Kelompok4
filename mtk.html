Lihat Perhitungan

Permisalan

X = Harga 1 Robot
Y = Harga 1 Hiasan dinding

Persamaan

Paket 1 → 2X + Y = 135.000
Paket 2 → 3Y + 2Y = 225.000

Penyelesaian

Eliminasi
2X + 3Y = 235.000 | x1
X + Y = 95.000 | x3
——————————
2X + 3Y = 235.000
2X + 3Y = 235.000
3X + 3Y = 285.000
—————————— -
-X = -50.000
X = 50.000

Substitusi
X + Y = 95.000
30.000 + Y = 95.000
Y = 95.000 - 50.000
Y = 45.000

Jadi, harga 1 robot adalah Rp50.000 dan harga 1 lampu hias adalah Rp45.000

SPLDV Isna Inayah (23)

Lihat Perhitungan

Permisalan

Y = Harga 1 Lampu Hias

Persamaan

Paket 1 → 2X + Y = 135.000
Paket 2 → 2X + 2Y = 225.000

Penyelesaian

Eliminasi
2X + Y = 135.000 | x2
2X + 2Y = 225.000 | x1
——————————

4X + Y = 270.000
2X + 2Y = 225.000
—————————— -
2X = 45.000
X = 22.500

2X + Y = 135.000
2.22.500 + Y = 135.000
Y = 135.000 - 45.000
Y = 90.00

Jadi, harga 1 robot adalah Rp45.000 dan harga 1 lampu hias adalah Rp90.000

SPLDV Verlita Maykhawa (35)

Lihat Perhitungan

Permisalan

X = Harga 1 Hiasan Dinding
Y = Harga 1 KeyTime

Persamaan

Paket 1 → 2X + Y = 170.000
Paket 2 → 2X + 2Y = 220.000

Penyelesaian

Eliminasi
2X + Y = 170.000 | x2
2X + 2Y = 220.000 | x3
——————————
4x + 2Y = 340.000
2X + 2Y = 220.000
2X = 120.000
—————————— -
X = 120.000
X = 60.0000

Substitusi
2X + Y = 170.000
2(60.000) + Y = 170.000
120.000 + Y = 170.000
Y = 170.000 - 120.000
Y = 50.000

Jadi, harga 1 hiasan dinding adalah Rp60.000 dan harga 1 KeyTime adalah Rp50.000
